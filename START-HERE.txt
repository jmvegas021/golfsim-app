========================================================
  WANT TO RUN THE APP?  READ THIS FIRST
========================================================

Do NOT use "Code -> Download ZIP" (the green Code button).
That download is SOURCE CODE and will not run by itself.

Instead (recommended):

  1. Open:
     https://github.com/jmvegas021/golfsim-app/releases

  2. Download:
     GsproLighting-win-Setup.exe

  3. Run Setup once, then launch from the shortcut

  4. Settings → Updates  (or tray → Check for updates…)

Portable alternative (still supported):

  Download GsproLighting-windows-x64.zip → unzip → GsproLighting.exe

No .NET install required.

More detail: SETUP-UPDATES.txt

--------------------------------------------------------
This folder is for developers who want to change the code.
Building it needs the .NET 8 SDK.
